HYDERABAD HOUSE PRICE PREDICTION APP

Files:
- app.py: Streamlit application
- Hyderbad_House_price.csv: Your Hyderabad house-price dataset
- requirements.txt: Required Python libraries

Run on Windows:
1. Extract this ZIP file.
2. Open the extracted folder in File Explorer.
3. Click the address bar, type cmd, and press Enter.
4. Run: py -m pip install -r requirements.txt
5. Run: py -m streamlit run app.py
6. The app opens in your browser.

IMPORTANT:
Keep app.py and Hyderbad_House_price.csv in the same folder.
The app loads this CSV automatically. The optional sidebar uploader
can be used if you want to test a different CSV.
The dataset's price(L) values are displayed in lakh rupees.
